ZAPRET — Windows-панель с автоматическим подбором ALT

1. Скачайте готовый ZIP из Releases и распакуйте полностью.
2. Откройте ZapretPanel.exe и подтвердите стандартный запрос UAC.
3. Нажмите «Запустить». Стратегия подбирается автоматически.

«Подобрать заново» повторяет подбор без приоритета сохранённого профиля.
«Остановить» останавливает zapret этой сборки.
Разрешены только ALT и ALT2–ALT13. VPN, VMware, SSH и ProxyBridge не запускаются.
При подборе Discord закрывается; после успешного выбора запустите Discord снова.
Журнал: logs/zapret.log. Выбранная стратегия: logs/zapret-strategy.txt.
Проверки HTTP не подтверждают стабильность голосового соединения.
Профили ALT не являются гарантией отсутствия влияния на другие сайты.
Если работает другая сборка zapret, остановите её перед запуском.
Закрытие панели после окончания проверки оставляет zapret работающим.

Панель — обычное приложение .NET Framework, запускается без PS1 и изменения политики PowerShell.
Нужные компоненты .NET Framework штатно присутствуют в Windows 10/11.
EXE пока не подписан сертификатом издателя. Windows/SmartScreen или антивирус могут выдавать предупреждения.
Это не подтверждение ложного срабатывания; не отключайте защиту и не добавляйте автоматические исключения.

Для пользователей GitHub предназначен готовый ZIP из Releases, не кнопка Code > Download ZIP.
Исходник панели: native/ZapretPanel.cs. Сборка на Windows: native/build.cmd.
